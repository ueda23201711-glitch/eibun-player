# 字幕プレイヤー

英文リーダー（eibun-reader）の「🎞 手元の動画と字幕で読む」で入れた動画を、iPhone・iPad の画面いっぱいに、大きな英語と日本語の字幕で見るアプリです。
https://ueda23201711-glitch.github.io/eibun-player/

- データは英文リーダーと共通（Firebase の memos/合言葉/reader）。このアプリは読むだけで、書き換えません。
- 動画は、この端末に保存してある動画（英文リーダーと同じ保存場所）を先に使い、なければ Google ドライブから再生します（英文リーダーと同じ Apps Script）。
- 縦画面：動画を上に置き、その下の空き全部を字幕に使います。横画面：動画を画面いっぱいにして字幕を重ねます。
- 暗証番号ロックは英文リーダーの lock.js を使います。
