# 字幕プレイヤー

英文リーダー（eibun-reader）の「🎞 手元の動画と字幕で読む」で入れた動画や、YouTube から読み込んだ英文の動画を、iPhone・iPad の画面いっぱいに、大きな英語と日本語の字幕で見るアプリです。
https://ueda23201711-glitch.github.io/eibun-player/

- データは英文リーダーと共通（Firebase の memos/合言葉/reader）。このアプリは読むだけで、書き換えません。
- 動画は、この端末に保存してある動画（英文リーダーと同じ保存場所）を先に使い、なければ Google ドライブから再生します（英文リーダーと同じ Apps Script）。
- 縦画面：動画を上に置き、その下の空き全部を字幕に使います。横画面：動画を画面いっぱいにして字幕を重ねます。
- 暗証番号ロックは英文リーダーの lock.js を使います。
- YouTube の英文は YouTube の埋め込みプレイヤーで再生し、字幕は YouTube のものではなく、英文リーダーの英語字幕と日本語訳を自前で表示します（埋め込み禁止の動画は再生できません）。
- 英文リーダーで「元の動画」のリンクを入れてある場合は、再生画面の上に「🔗 元の動画」を出します（YouTube は今の位置から YouTube で開きます）。
- 英文リーダーの中にも同じものを置いています（eibun-reader/player.html。`sh build-reader-copy.sh ../eibun-reader` で、この index.html から作ります）。英文リーダーのアプリからは、同じアプリの中で行き来するので、取り込んだ動画・合言葉が共通になります。
- 行き来するときは、その時間から続けます。再生中だった場合は、音を消して自動で続きを再生します（「🔇 … タップで音を出す」で音が出ます）。
